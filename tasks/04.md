# Tarefa 04: Centralizar dados e expandir página de experiência

## Prompt Original

```
eu quero que os certificados sema exibidos em timelien e tenha alguma forma de eu referenciar eles e colocar informções, como por exemplo teria certificado1 ae eu colocaria informações sobre ele para poder aparecer na timelihe, isso tudo ficaria guardado em um arquivo de data, estou pensando na possibilidade de centralizarmos as informações em uma pasta chamada data e coma rquivos dentro tipo projects.ts ou json a forma que for melhor ae seria arrays com os porjetos do portfolio, assim como em @src/app/(portfolio)/projects/page.tsx  uusanmos data e tmb em @src/app/(portfolio)/experience/_components/experience-hero.tsx  ae poderia ser os mesmos sabe, vamos pensar nisso com perguntas para enterdemos melhor
```

## Decisões Tomadas

### 1. Estrutura de Arquivos de Dados

```
src/data/
├── certificates.ts    # Certificados
├── education.ts       # Formação acadêmica
├── skills.ts          # Habilidades e Idiomas
```

**Nota:** Projetos já existem em `src/app/(portfolio)/projects/_components/projects-grid.tsx` como arrays no mesmo arquivo. O usuário prefere manter assim por enquanto.

### 2. Formato dos Dados

- **TypeScript (.ts)**: Preferido pelo usuário para poder ter tipagem e inteligência
- **Referência de certificados**: Caminho do arquivo em `public/certificates/` + dados em TS

### 3. Campos dos Certificados

| Campo | Tipo | Obrigatório | Exemplo |
|-------|------|-------------|---------|
| id | string | Sim | "cert1" |
| title | string | Sim | "React + TypeScript" |
| institution | string | Não | "Origamid" |
| date | string | Não | "2024" |
| filePath | string | Sim | "/certificates/react-origamid.pdf" |
| technologies | string[] | Não | ["React", "TypeScript"] |
| description | string | Não | "Curso de React com TypeScript" |

### 4. Estrutura da Página Experiência

A página terá 4 seções separadas:

1. **Formação Acadêmica** (Timeline)
   - IFNMG ADS (2024-2026)
   - Status: em andamento

2. **Certificados** (Timeline)
   - Referência ao PDF em public/certificates/
   - Cada item clicável abre o PDF

3. **Projetos FACEL** (Timeline)
   - Projetos da faculdade

4. **Habilidades/Idiomas** (Grid ou lista)
   - Linguagens de programação
   - Idiomas (ex: Inglês Técnico Básico)

### 5. Arquivos de Certificados Existentes

```
public/certificates/
├── Certificado - Isaque.pdf
├── certificado react origamid.pdf
├── Certificado_Fundamentos do Node.js.pdf
└── ReactTypescriptOrigamid.pdf
```

### 6. Regras de Implementação

- Usar padrão existente do projeto (Badge + Título + Seção)
- Timeline cronológica (mais antigo → mais recente)
- Separar formação acadêmica, certificados e projetos FACEL em seções distintas
- Usar tokens de cores do tema (nunca hard-coded)
- Um componente por arquivo
- Sem comentários no código

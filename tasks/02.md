## Regras de Implementação

1. **Criar como página SEPARADA** (não parte da Home)
   - Cada página deve ser um frame top-level isolado no documento

2. **Manter fidelidade total** ao design system existente
   - Usar EXATAMENTE as cores, fontes e espaçamentos especificados
   - Não inventar novos valores

3. **Ícones SVG**
   - Usar os ícones existentes do arquivo ou ícones Lucide/Feather padrão
   - Manter o mesmo estilo visual

4. **Responsividade**
   - Desktop first (1280px de largura)
   - Similar ao breakpoint existente

5. **Posicionamento do Header**
   - O header deve ter `layoutPosition: "absolute"` para ficar fixo no topo
   - Usar x=0, y=0

6. **Padding do Body Principal**
   - Manter o padding superior: 192px (para dar espaço ao header)
   - Alinhar ao centro com `alignItems: "center"`

7. **Largura máxima do conteúdo**
   - Main section: 1152px
   - Centralizado no viewport
